# AGENTS.md

Guide for coding agents working on this project. Repository: https://github.com/tsnaketech/orange-tv
(app id `io.github.tsnaketech.orangetv`).

## The project

Android app for **Fire TV** (tested on Fire TV Stick 4K Max, Fire OS 8 / Android 11, API 30) that shows
the official Orange TV website of the user's country (`https://tv.orange.fr/` by default, see `Sites.kt`) full screen in a WebView and makes it usable with the
remote. **Personal** use only: the app reuses Orange's service and name, it must not be published or
distributed without Orange's permission.

What the app adds to the site:

- spatial navigation (arrows + OK) between clickable elements, with a selection frame;
- automatic wake-up of the video player controls, Back closes an open panel first;
- channel ± keys, ⏪/⏩ (±10 s within the time-shift window), play/pause;
- sign-in from the phone via QR code (small local HTTP server, active only on the sign-in page).

## Structure

| File | Role |
|---|---|
| `app/src/main/java/io/github/tsnaketech/orangetv/MainActivity.kt` | WebView, remote keys, QR code, automatic credential filling, free cursor (short press on Menu), site chooser (long press on Menu) |
| `app/src/main/java/io/github/tsnaketech/orangetv/Sites.kt` | One Orange web app per country (FR, BE, PL, RO, SK, ES), picked with a long press on Menu (kept in SharedPreferences) or else from the system region, France by default: start URL, sign-in URL (QR code), player labels, hidden tooltips, extra clickable selectors and carousel arrows (Spain: its tiles are plain divs and its own D-pad focus only covers the top menu in a browser), channel ± as Page Up / Down (Spain). FR is tested signed in; ES navigation was checked on the TV without an account; the others come from reading each site's code |
| `app/src/main/java/io/github/tsnaketech/orangetv/SpatialNav.kt` | JS script injected into the page: navigation, styles (frame, hidden elements), closing panels, seek, zapping |
| `app/src/main/java/io/github/tsnaketech/orangetv/PhoneInputServer.kt` | Local HTTP server + phone page (username + password), protected by a random token |
| `app/src/main/java/io/github/tsnaketech/orangetv/I18n.kt` | App texts in FR, EN, NL, DE, RO, PL, SK, ES. TV: Fire OS language; phone page: the phone's `Accept-Language` header; English by default. Each Orange site picks its own language (FR: always French) |
| `app/src/test/.../PhoneInputServerTest.kt` | JVM tests of the server (token, decoding, empty fields, language choice) |
| `app/src/test/.../SitesTest.kt` | JVM tests of the site choice, sign-in URLs and label regexes |
| `app/src/main/res/xml/network_security_config.xml` + `res/raw/*.pem` | Extra trusted certificates for the RO and BE sites (missing from Fire OS 8), with their SHA-256 |
| `app/src/main/res/drawable-nodpi/ic_app.png` | Icon (this is what the Fire TV launcher shows) — generated by `tools/make_icon.py` |
| `app/src/main/res/drawable/banner.png` | 16:9 banner — generated by `tools/make_banner.py` |
| `docs/screenshots/<country>.jpg` | README screenshots taken on the TV (1280×720; the app's QR code is blurred: it holds the TV's IP and a sign-in token) |
| `README.md`, `README.<code>.md` (the German one is `README.lu.md`: it covers Luxembourg) | User-facing overview, one per language in `I18n.kt`, with the Orange specifics of the matching countries. Keep all 8 in sync |
| `tools/cdp.mjs` | Evaluates JS in the TV's WebView via DevTools (inspecting the site's DOM) |

## Commands

Windows, PowerShell. `adb` is installed by winget (not in the PATH of terminals opened before the install):

```powershell
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"
.\gradlew.bat testDebugUnitTest      # tests
.\gradlew.bat installDebug           # build + install on the connected TV
adb connect <TV_IP>:5555             # Fire TV IP on the local network (Settings > My Fire TV > About > Network)
adb shell am start -n io.github.tsnaketech.orangetv/.MainActivity
adb logcat -s TvWeb                  # received keys (Log.i "touche KEYCODE_…")
```

Regenerate the visuals (requires Pillow and Windows' Segoe UI font):

```powershell
python tools/make_icon.py
python tools/make_banner.py
```

## Release

`.github/workflows/release.yml`, run by hand only (GitHub > Actions > Release APK > Run workflow): runs the tests,
builds the signed release APK and publishes it as release `v<versionName>` with `orange-tv-<versionName>.apk`.
Bump `versionCode` and `versionName` in `app/build.gradle.kts` first: a tag that already exists makes it fail.

One-time setup, done by the repo owner (the keystore and its passwords never go in the repo):

```powershell
& "C:\Program Files\Android\Android Studio\jbr\bin\keytool.exe" -genkeypair -keystore orangetv-release.jks `
  -alias orangetv -keyalg RSA -keysize 4096 -validity 10000
gh secret set KEYSTORE_BASE64 -b ([Convert]::ToBase64String([IO.File]::ReadAllBytes("orangetv-release.jks")))
gh secret set KEYSTORE_PASSWORD   # prompts for the value
gh secret set KEY_ALIAS -b orangetv
gh secret set KEY_PASSWORD
```

- Keep `orangetv-release.jks` and its passwords outside the repo, backed up: without them, no later version can
  be installed over the current one (Android requires the same signature).
- A release APK has another signature than local debug builds: switching the TV from one to the other needs an
  uninstall, which erases the Orange session.
- Locally, `assembleRelease` fails in `lintVitalAnalyzeRelease` with Android Studio's Java 25 (AGP 8.7 lint);
  the workflow uses Java 17. Without the `SIGNING_*` variables the local release APK is unsigned.

## Verifying a change

There is no Fire TV emulator: verify on the real TV.

- `adb shell input keyevent <code>` to simulate the remote (19/20/21/22 arrows, 23 OK, 4 Back,
  89/90 ⏪/⏩, 166/167 channel ±).
- Screenshot: `adb shell screencap -p /sdcard/c.png` then `adb pull /sdcard/c.png`.
- Page state: `adb forward tcp:9222 localabstract:webview_devtools_remote_<pid>` then
  `node tools/cdp.mjs query.js` (the debug build enables WebView debugging).

## Known pitfalls

- **Orange's sites change without notice.** Several tweaks rely on their labels
  (`Chaîne suivante`, `Fermer`, `Masquer la liste des chaînes`, `.tooltip` class…), kept per country in
  `Sites.kt`. If a feature breaks, inspect the DOM with `tools/cdp.mjs` before changing anything.
- **Other countries' sites** are different products (SDS Titan in BE, Viaccess-Orca in PL, Solocoo in RO,
  nangu.TV in SK, a 10-foot Angular app in ES). None has channel ± buttons except FR. They all need the
  desktop Chrome UA and Widevine, and most block playback outside their country.
- **Certificates on Fire OS 8**: a site that loads on the PC but stays blank on the TV is usually
  `net_error -202` (`adb logcat -s chromium:E`). Fire OS lacks recent roots (Sectigo R46, GlobalSign R46: RO) and
  Android never fetches a missing intermediate (orangetvgo.be does not send it). Fix in
  `res/xml/network_security_config.xml` with the certificate in `res/raw`, never by ignoring SSL errors.
- **Luxembourg and Moldova have no Orange TV website** (tv.orange.lu, tvgo.orange.md, tv.orange.md, orangetv.md
  do not exist), only native Android TV apps on Google Play (`com.orange.lu.android_tv`,
  `com.orange.md.tv.android`). Nothing to add to `Sites.kt`: they fall back to the French site. Fire OS has no
  Google Play; do not suggest sideloading those APKs from mirror sites. The answer for those users is a Google TV /
  Android TV device.
- **Video player**: its controls only appear on mouse movement; `MainActivity.navigate()` wiggles the mouse
  before navigating when a video fills the screen. In live, `video.duration` is infinite: use `video.seekable`.
- **The mute key never reaches the app** (handled by Fire OS / the TV).
- **Fire TV launcher**: for an app installed outside the Appstore, it shows the icon (not the banner) and caches
  the visuals. An icon change only shows after **uninstall + reinstall**, which erases the user's Orange
  session: warn them first.
- **Credentials**: never log or store them. They only live in memory (~30 s) while being filled in. The QR code
  server uses plain HTTP on the local network (accepted shortcut, home use).
- **User agent**: the app presents itself as desktop Chrome, otherwise the site redirects to the mobile app.

## Conventions

- Comments in English; a comment only explains the *why*. User-facing texts live in `I18n.kt`; the site's
  French labels the code looks for (`Chaîne suivante`, `Fermer`…) stay as they are.
- Minimal change: no new dependency unless necessary (only `zxing` and `junit`).
- Every new behavior is verified on the TV (screenshot or state via `cdp.mjs`) before being announced.
